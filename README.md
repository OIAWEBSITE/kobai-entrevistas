# Revista Kōbai — Entrevistas

Maqueta estática para GitHub Pages, sin banner, navegación institucional ni pie institucional. Ocho entrevistas reales con títulos, personas, autores, ediciones y enlaces a la revista. Diseño responsive con búsqueda y filtro por año.

## Imágenes
Las imágenes originales de la página institucional **no están incluidas** en este paquete, porque no se pudo recuperar una URL verificable para cada una. La maqueta incluye fondos tipográficos abstractos de manera provisional (no son las fotografías originales).

Para agregar las imágenes institucionales autorizadas, crea la carpeta `imagenes/`, sube allí los ocho archivos y edita `script.js`: cambia `imagen:''` por `imagen:'imagenes/nombre-de-la-imagen.jpg'` en cada elemento. La imagen se mostrará automáticamente.

## Publicación
Sube `index.html`, `styles.css` y `script.js` a la raíz de un repositorio público y activa Settings → Pages → Deploy from a branch → main → / (root).

GitHub Pages: `https://USUARIO.github.io/NOMBRE-REPOSITORIO/`. Para utilizar `*.uniandes.edu.co` se necesita aprobación y configuración DNS de Uniandes. No es posible registrar un dominio `.git` gratuito con GitHub Pages.
